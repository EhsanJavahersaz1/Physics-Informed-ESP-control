
# Learning-Augmented ESP with Physics-Informed Neural Networks

This project explores the integration of classical vehicle dynamics with modern Deep Learning frameworks. It demonstrates the ability to enforce physical constraints within a PyTorch-based neural network.

## Key Features
- **Physics-Informed Loss:** Incorporates kinematic equations directly into the training loop.
- **Stability Control:** Predicts vehicle state margins by learning from nonlinear dynamics.
- **Academic Relevance:** Designed to bridge the gap between control theory and robotic foundation models.

## How to Run
1. Install requirements: `pip install torch`
2. Run the training script: `python train.py`
